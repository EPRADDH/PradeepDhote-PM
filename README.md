# Pradeep Dhote - Executive Portfolio

A premium, business-focused executive portfolio website for **Pradeep Dhote** — Digital Transformation Leader, Technical Project Manager, Telecom AI Consultant, and Private 5G Expert.

Designed with a modern, minimal aesthetic inspired by high-end consulting firms.

## 🚀 Key Features

- **Pure Native Stack**: Built using standard HTML5, CSS3, and Vanilla JavaScript with zero external frameworks (No React, Angular, Vue, Bootstrap, or jQuery).
- **11 Dedicated Executive Pages**:
  1. `index.html` - Executive Hero, Professional Intro, Animated Metrics, Flagship Solutions
  2. `about.html` - Career Story, Leadership Philosophy, Mission & Vision, Expertise Matrix
  3. `leadership.html` - Interactive Vertical Career Timeline & Key Milestones
  4. `experience.html` - Detailed Career Roles, Responsibilities & Quantifiable Outcomes
  5. `telecom-portfolio.html` - AI EMS, Private 5G, O-RAN, Telco Cloud Solutions
  6. `ai-portfolio.html` - Generative AI, RAG, Agentic AI Workflows & Predictive Analytics
  7. `project-management.html` - PMP® Case Studies, Budget Governance, Risk Matrices
  8. `certificates.html` - Verified Credentials (PMP, SAFe, AWS, Telecom AI, Private 5G)
  9. `knowledge-center.html` - Resource Hub with Live Search & Downloadable Whitepapers
  10. `resume.html` - Printable Executive Resume Preview & Download
  11. `contact.html` - Interactive Executive Advisory Request Form
- **Light & Dark Mode**: Persistent theme switcher with custom CSS variables (`data-theme="dark"`).
- **Smooth Micro-Interactions**: Animated metric counters, scroll reveal animations, dynamic typing effect in hero, interactive filter tabs, live resource search.
- **Mobile Responsive**: Custom media query breakpoints, drawer navigation menu, accessible touch targets.

## 📦 Deploying to GitHub Pages

This project is built pure static HTML5/CSS3/JS, making it ready for instant zero-configuration deployment to GitHub Pages.

1. Push this entire repository to GitHub.
2. Go to **Settings > Pages** in your GitHub repository.
3. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
4. Select the `main` branch and `/ (root)` folder, then click **Save**.
5. Your executive portfolio will be live at `https://<your-username>.github.io/<repo-name>/`.

## 🛠️ Local Development

```bash

# Build multi-page static site for production
npm run build
```
