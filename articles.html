GitHub Pages Auto-Deploy

Connect your GitHub repository so writing or deleting an article from this UI automatically commits public/data/articles.json and triggers the included GitHub Actions Pages deploy workflow.

1. Enable Pages: Push this project to GitHub, then open Settings → Pages → Source: GitHub Actions.
2. Create Token: Create a GitHub Fine-Grained Token with Contents: Read and write access on your repository.
3. Auto-Update Live Site: Any article published or deleted in this UI commits straight to GitHub and rebuilds your live site in ~45 seconds.
